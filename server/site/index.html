从开学，到每一次调课。

01 / 录入

课表，不必从头填。

从正方教务网页、文字型 PDF 或粘贴文字导入。先核对再保存，也可以手动编辑。

不同学校模板可能需要适配
02 / 安排

临时变化，也有条理。

多学期、单双周、夏冬作息。月历多选停补课，或只调整某一堂课的时间和教室。

考试使用独立日期与考场
03 / 提醒

下一堂课，提前知道。

课前提醒、上课进度与课间状态。系统提醒由你开启，离线时也能查看课程。

送达受系统权限和省电策略影响

你的课表，由你决定

留在本机。
分享，由你选择。

日常查看与编辑保存在手机里，没有广告 SDK，也没有统计服务。教务登录由你在学校页面完成；PDF 在本机解析。

想把课表交给朋友时，再生成分享口令。默认不上传备注和考试；只有主动分享或开启持续分享后，所选内容才会发送到分享服务器。

分享服务器可读取已上传内容，持有口令的人也可以读取。卸载前请导出备份；分享凭证与跟随关系不包含在普通课表备份中。
